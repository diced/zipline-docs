---
title: 'Windows: ShareX'
description: Use ShareX to upload files to Zipline on Windows
---

Zipline can generate a `.sxcu` (ShareX Custom Uploader) file for you to use with ShareX. With this you can easily upload files to your Zipline instance using ShareX.

## Downloading

1. Head to your settings page (click your user icon in the top right corner)

![manage account](/img/docs/uploader-manage-account.png)

2. Scroll down to the "Generate Uploaders" section and click "ShareX"

![generate uploaders](/img/docs/generate-uploaders-section.png)

3. Feel free to customize the options provided, then at the bottom you click "Download" to download the `.sxcu` file.

![customize options](/img/docs/sharex-3.png)

<Callout type='note'>
  If you select "Shorten URL" instead of "Upload File" you can use the `.sxcu` file to be your custom URL
  shortener instead of the file uploader within ShareX.
</Callout>

## Importing

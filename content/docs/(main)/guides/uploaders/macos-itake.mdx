---
title: 'macOS: iTake'
description: Use iTake to upload screenshots/recordings/files on macOS
---

Zipline can generate a `.itup` (iTake Custom Uploader) file for you to use with [iTake](https://github.com/SerStars/iTake). With this you can easily upload screenshots/recordings on MacOS to your Zipline instance using iTake.

## Downloading

1. Head to your settings page (click your user icon in the top right corner)

![manage account](/img/docs/uploader-manage-account.png)

2. Scroll down to the "Generate Uploaders" section and click "iTake"

![generate uploaders](/img/docs/generate-uploaders-section.png)

3. Feel free to customize the options provided, then at the bottom you click "Download" to download the `.itup` file.

![customize options](/img/docs/itake-1.png)

## Importing

4. Follow the steps below to import the `.itup` file into iTake.

![open uploaders](/img/docs/itake-2.png 'Open iTake through the menu bar and click on "Uploaders" then "Import"')

![downloaded file](/img/docs/itake-3.png 'Import the downloaded .itup file into iTake by clicking the "Import" button in Uploader settings')

![see uploader](/img/docs/itake-4.png 'You should now see the "Zipline" next to "Active Uploader".')

![set as default](/img/docs/itake-5.png 'Click on the dropdown menu and set the upload destination as Zipline')

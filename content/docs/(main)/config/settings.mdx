Manage server settings at **Server Settings** (`/dashboard/admin/settings`). Only super administrators can view or change them.

![settings sidebar access](/img/docs/config-settings-1.png)

You can also set the environment variables below in `.env` or your Compose configuration. Environment variables override dashboard values and make those fields read-only. The tables show types and examples; example values aren't necessarily defaults.

[Core](/docs/config/core) and [datasource](/docs/config/datasource) options are configured only through the environment. Some dashboard settings also require a restart after saving.

## Core

Controls generated URLs, temporary storage, and trusted proxy headers. Most core settings require a restart.

For a reverse proxy, enable **Trust Proxies** and set **Trusted Proxies** to its IP addresses or CIDRs. With an empty list, forwarded headers are ignored and clients behind the proxy share rate limits. See [Reverse Proxy](/docs/guides/reverse-proxy#after-setting-up) for examples.

Temporary files default to `./uploads/.tmp`. Moving them to another filesystem, including tmpfs, can reduce local upload performance.

| Variable                 | Type       | Example               |
| ------------------------ | ---------- | --------------------- |
| `CORE_RETURN_HTTPS_URLS` | `boolean`  | `true`                |
| `CORE_DEFAULT_DOMAIN`    | `string`   | `zipline.example.com` |
| `CORE_TEMP_DIRECTORY`    | `string`   | `./uploads/.tmp`      |
| `CORE_TRUST_PROXY`       | `boolean`  | `true`                |
| `CORE_TRUSTED_PROXIES`   | `string[]` | `127.0.0.1,::1`       |

See the other [core settings](/docs/config/core).

### Return HTTPS URLs

Enable this when your instance uses HTTPS, including when TLS terminates at a reverse proxy. Generated URLs use `https://`, and cookies are marked `Secure`. Leave it disabled for an HTTP-only instance, where secure cookies wouldn't be sent by the browser.

## Chunks

Controls [chunked uploads](/docs/api/chunked-uploads). Dashboard uploads larger than **Max Chunk Size** are split into requests of **Chunk Size**, allowing large files to pass through proxies with per-request size limits.

| Variable         | Type      | Example |
| ---------------- | --------- | ------- |
| `CHUNKS_MAX`     | `string`  | `95mb`  |
| `CHUNKS_SIZE`    | `string`  | `25mb`  |
| `CHUNKS_ENABLED` | `boolean` | `true`  |

## Multi-Factor Authentication

Configure passwordless passkey login and time-based one-time passwords (TOTP):

- [Passkeys](/docs/guides/passkeys) use a device, phone, or security key. Configure the relying party ID and origin before users register a passkey.
- [TOTP](/docs/guides/2fa) adds an authenticator code after a username and password login. **Issuer** is the account label shown in the authenticator app.

The passkey prompt depends on the user's operating system and browser:

![macOS security dialog](/img/docs/config-settings-passkey-macos.png 'A macOS security dialog showing a passkey.')

| ---------------------- | --------- | ----------------------------- |

## Files

Controls file uploads, naming, and serving. **Route** can be `/` to serve files from the domain root. **Remove GPS Metadata** attempts to remove EXIF GPS data from uploaded images.

- **Assume Mimetypes** detects file types from their contents rather than trusting the browser. Enable it when restricting MIME types; see [Hardening](/docs/guides/hardening#assume-mime-types).
- **Disabled Types** lists MIME types to reject, such as `text/html,application/javascript`.
- **Default MIME for Disabled Types** serves those types with a replacement MIME type instead of rejecting them. For example, `application/octet-stream` makes the browser download them. Leave it blank to reject the upload.
- **Extensionless URLs** lets file links work without extensions. Upload responses still include extensions unless the user requests an extensionless URL through dashboard upload options or the [`x-zipline-extensionless` header](/docs/guides/upload-options#extensionless-urls). If names overlap, the newest matching upload is used.

| Variable                            | Type       | Example                            |
| ----------------------------------- | ---------- | ---------------------------------- |
| `FILES_ROUTE`                       | `string`   | `/u`                               |
| `FILES_LENGTH`                      | `number`   | `6`                                |
| `FILES_DEFAULT_FORMAT`              | `string`   | `random`                           |
| `FILES_DISABLED_TYPES`              | `string[]` | `text/html,application/javascript` |
| `FILES_DISABLED_TYPES_DEFAULT`      | `string`   | `application/octet-stream`         |
| `FILES_DISABLED_EXTENSIONS`         | `string[]` | `exe,bat,dmg`                      |
| `FILES_MAX_FILE_SIZE`               | `string`   | `100mb`                            |
| `FILES_MAX_FILES_PER_UPLOAD`        | `number`   | `10`                               |
| `FILES_DEFAULT_EXPIRATION`          | `string`   | `30d`                              |
| `FILES_ASSUME_MIMETYPES`            | `boolean`  | `true`                             |
| `FILES_DEFAULT_DATE_FORMAT`         | `string`   | `YYYY-MM-DD_HH:mm:ss`              |
| `FILES_REMOVE_GPS_METADATA`         | `boolean`  | `true`                             |
| `FILES_RANDOM_WORDS_NUM_ADJECTIVES` | `number`   | `3`                                |
| `FILES_RANDOM_WORDS_SEPARATOR`      | `string`   | `-`                                |
| `FILES_DEFAULT_COMPRESSION_FORMAT`  | `string`   | `webp`, `jpg`                      |
| `FILES_EXTENSIONLESS_URLS`          | `boolean`  | `true`                             |

## Ratelimit

Limits requests to `/api/upload` and `/api/shorten`. **Max Requests** is the number allowed per **Window**, measured in seconds. The allow list contains IP addresses that bypass this limit.

| Variable                 | Type       | Example           |
| ------------------------ | ---------- | ----------------- |
| `RATELIMIT_ENABLED`      | `boolean`  | `true`            |
| `RATELIMIT_MAX`          | `number`   | `10`              |
| `RATELIMIT_WINDOW`       | `number`   | `60`              |
| `RATELIMIT_ADMIN_BYPASS` | `boolean`  | `true`            |
| `RATELIMIT_ALLOW_LIST`   | `string[]` | `1.1.1.1,8.8.8.8` |

## Website

Controls instance branding and default appearance. See [Dashboard customization](/docs/guides/customize-dash) for setup instructions.

- **Default Avatar** is a server-side image path.
- **Terms of Service** is a server-side Markdown path. New users must agree to it when registering.
- **External Links** is a JSON array of objects with `name` and `url` fields. Use the [External Links Builder](/docs/guides/external-links).
- Theme settings apply when the user hasn't selected their own theme, including on public pages.

| Variable                        | Type      | Example                                              |
| ------------------------------- | --------- | ---------------------------------------------------- |
| `WEBSITE_TITLE`                 | `string`  | `Zipline`                                            |
| `WEBSITE_TITLE_LOGO`            | `string`  | `https://example.com/logo.png`                       |
| `WEBSITE_EXTERNAL_LINKS`        | `json`    | `[{"name":"Docs","url":"https://zipline.diced.sh"}]` |
| `WEBSITE_LOGIN_BACKGROUND`      | `string`  | `https://example.com/bg.png`                         |
| `WEBSITE_LOGIN_BACKGROUND_BLUR` | `boolean` | `true`                                               |
| `WEBSITE_DEFAULT_AVATAR`        | `string`  | `/absolute/path/to/file`                             |
| `WEBSITE_TOS`                   | `string`  | `/absolute/path/to/markdown.md`                      |
| `WEBSITE_THEME_DEFAULT`         | `string`  | `system`                                             |

## PWA

Provides a web app manifest so users can install Zipline from their browser.

Make the required favicon files available in `public/`. For Docker, mount them into the container; the files are available in the [Zipline repository](https://github.com/diced/zipline/tree/trunk/public/).

| Variable               | Type      | Example                |
| ---------------------- | --------- | ---------------------- |

| `PWA_TITLE`            | `string`  | `Zipline PWA`          |
| `PWA_SHORT_NAME`       | `string`  | `Zipline`              |
| `PWA_DESCRIPTION`      | `string`  | `File & URL shortener` |
| `PWA_BACKGROUND_COLOR` | `string`  | `#ffffff`              |
| `PWA_THEME_COLOR`      | `string`  | `#000000`              |

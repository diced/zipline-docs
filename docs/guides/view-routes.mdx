# View Routes

View Routes on Zipline allow you to customize the appearance of files when they are viewed through the browser. By this we mean that instead of just showing the raw file and letting the browser handle it, the file is rendered in a more "user-friendly" way.

![View Route Example](/img/docs/view-routes-1.png)

There is an option to download it, and clicking on the image/video, etc. will enlarge it within the page.

## Enabling View Routes

1. Go to your Zipline dashboard, and head over to the your user settings in the top right corner.
2. Scroll down to the **View Routes** section.
3. Toggle the `Enable View Routes` option to enable view routes.

![Enable View Routes](/img/docs/view-routes-2.png)

Additionally, you can enable the `Show Mimetype` option, to show the mimetype of the file at the top of the page (e.g. `image/png`).

## Adding Custom Text

You can add custom text to the view route page by entering it into the `View Content` text field. This text will be displayed below the file preview.

![Custom Text Field](/img/docs/view-routes-3.png)

<Alert type='note'>
  You can use HTML in the `View Content` field to further customize the
  appearance of the view route page, although it is very limited.
</Alert>

### Examples

Here are some examples of what you can do with the `View Content` field:

- `<h3>{file.name} was uploaded at {file.createdAt::locale}</h3>` - Displays the name of the file and the date it was uploaded.

![Custom Text Example](/img/docs/view-routes-4.png)

For more information on the available variables, see the [Variables](/docs/guides/variables) guide.

## View Content Alignment

This option allows you to change the alignment of the `View Content` text. You can choose between `Left`, `Center`, and `Right`.

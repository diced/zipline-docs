# ziplinectl read-config

Output the current configuration as JSON.

## Options

| Option           | Description                                     |
| ---------------- | ----------------------------------------------- |
| `-f`, `--format` | Format the JSON output for easier reading.      |
| `-h`, `--help`   | Display options and arguments for this command. |

## Usage

```bash
ziplinectl read-config
```

or

```bash
ziplinectl read-config -f
```

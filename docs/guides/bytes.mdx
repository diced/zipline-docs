# Bytes

Some settings use human readable byte sizes. Here is a table of the byte sizes and their human readable counterparts.

| Unit | Bytes                                      |
| ---- | ------------------------------------------ |
| b    | 1 byte                                     |
| kb   | 1024 bytes                                 |
| mb   | 1024 \* 1024 bytes                         |
| gb   | 1024 \* 1024 \* 1024 bytes                 |
| tb   | 1024 \* 1024 \* 1024 \* 1024 bytes         |
| pb   | 1024 \* 1024 \* 1024 \* 1024 \* 1024 bytes |

# Android: Xshare

## Download Xshare

Head over to [https://github.com/tsudoko/xshare/releases/latest](https://github.com/tsudoko/xshare/releases/latest) and grab the latest APK.

## Download the sxcu file

You will need to generate a sxcu file from Zipline. To do this you can follow the steps on the [sharex uploader](/docs/guides/uploaders/sharex) page (stop after you download the file.)

## Importing within Xshare

Once you have installed Xshare, open the app. Click the + button, then click on "From", then "File" as shown below

![](/guides/android-xshare-1.png)

Then you will be prompted to select the file. Find the sxcu file you had downloaded previously and select it. If you are having trouble finding it, look in `Downloads`.

<Alert type="info">
If you see an error that says something similar to "Specified file doesn't have .sxcu extension", ignore it and tap "Proceed Anyway".
</Alert>

You will now have to click on "Default uploader" and select the one that says something similar to "Zipline - your domain - File".

## How To Use

Navigate to any file, or photo, and then click the Share icon. Find the `Xshare` app and click on it, you should see a progress notification and then the link inside it once it finishes. If you have toggled the "Copy to clipboard" option, it will be copied to your clipboard once it finished.

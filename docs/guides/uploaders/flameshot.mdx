# Flameshot

This section requires [Flameshot](https://www.flameshot.org/), [jq](https://stedolan.github.io/jq/), and [xsel](https://github.com/kfish/xsel).

## Downloading

1. Head over to your Settings page (click your user icon in the top right corner)
2. Scroll down to **Generate Uploaders**

![Generate Uploaders](/img/docs/flameshot-1.png)

3. Click on **Flameshot**, then enable any options that you would like

![](/img/docs/flameshot-2.png)

Once you download one save it to your computer, remember the path, and make the file executable.

### Through the terminal

```bash
chmod +x /path/to/zipline-script.sh
```

### Through the file manager

![Gnome Files (nautilus)](/img/docs/flameshot-3.png 'Make a file executable on GNOME Files')
![KDE (dolphin)](/img/docs/flameshot-4.png 'Make a file executable on KDE (Dolphin)')

### Extra: Set up a keyboard shortcut with KDE

Head over to the Settings app, and go to Custom Shortcuts. Create a new shortcut.
![](/img/docs/flameshot-kde-1.png)

Set the keyboard shortcut to whatever, usually `Print`.

![](/img/docs/flameshot-kde-2.png)

Set the command to the path of the script you downloaded.
![](/img/docs/flameshot-kde-3.png)

Hit `Apply` and you're done! You can now press `Print` to open the flameshot gui and once you take the screenshot it will upload it to Zipline then copy the URL.

## DIY

To upload files using Flameshot we will use a script. Replace $TOKEN and $HOST with your own values.

```shell title="ss.sh"
DATE=$(date '+%h_%Y_%d_%I_%m_%S.png');
flameshot gui -r > ~/Pictures/$DATE;

curl -H "Content-Type: multipart/form-data" -H "authorization: $TOKEN" -F file=@~/Pictures/$DATE $HOST/api/upload | jq -r .files[0].url | xsel -ib
```

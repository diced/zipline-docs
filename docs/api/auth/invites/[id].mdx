# /api/auth/invites/:id

View a specific invite by its ID.

<Alert type='info'>
  This endpoint requires [authentication](/docs/api/authentication).
</Alert>

<Alert type='info'>
  This endpoint requires administrator priviliges or higher.
</Alert>

## Path Parameters

| Name | Type   | Description                  |
| ---- | ------ | ---------------------------- |
| `id` | string | The unique ID of the invite. |

<ApiHeading type='GET'>Request</ApiHeading>

### Response

**Status:** `200 OK`

**Content-Type:** `application/json`

An [Invite](/docs/api/models/invite) object.

#### Example

```json
{
  "id": "cmb7c5d3n0002vcatximfhrf0",
  "createdAt": "2025-05-28T02:38:04.691Z",
  "updatedAt": "2025-05-28T02:38:04.691Z",
  "expiresAt": null,
  "code": "falpjX",
  "uses": 0,
  "maxUses": null,
  "inviterId": "cmb6042f500029kenox2u8npu",
  "inviter": {
    "username": "admin",
    "id": "cmb6042f500029kenox2u8npu",
    "role": "SUPERADMIN"
  }
}
```

### Error Responses

- **404 Not Found**

  If the invite with the specified ID does not exist.

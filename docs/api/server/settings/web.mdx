# /api/server/settings/web

Get or update server-wide configuration settings.

<Alert type='info'>
  This endpoint requires [authentication](/docs/api/authentication).
</Alert>

<ApiHeading type='GET'>Request</ApiHeading>

Retrieve the configuration as a authenticated user. By design this route doesn't include certain configuration properties like the datasource, ssl settings, and the core config. None of these options are needed for functionality on the dashboard so they are omitted.

### Response

**Status:** `200 OK`

**Content-Type:** `application/json`

Returns an object of `config` and `codeMap`.

| Property   | Type                          | Description                                                                                                                                                      |
| ---------- | ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `config` | [see below](#config-object) | The configuration object used for various options around the dashboard. |
| `codeMap` | [see below](#code-map)  | A list of languages and their extensions to be used on `/dashboard/upload/file`  |

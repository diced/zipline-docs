# /api/user/stats

View user statistics.

<Alert type='info'>
  This endpoint requires [authentication](/docs/api/authentication).
</Alert>

<ApiHeading type='GET'>Request</ApiHeading>

### Response

**Status:** `200 OK`

**Content-Type:** `application/json`

| Property         | Type                         | Description                                      |
| ---------------- | ---------------------------- | ------------------------------------------------ |
| `filesUploaded`  | `number`                     | Total number of files uploaded by the user.      |
| `favoriteFiles`  | `number`                     | Number of files the user has marked as favorite. |
| `views`          | `number`                     | Total views across all user files.               |
| `avgViews`       | `number`                     | Average views per file.                          |
| `storageUsed`    | `number`                     | Total storage used by user files, in bytes.      |
| `avgStorageUsed` | `number`                     | Average file size, in bytes.                     |
| `urlsCreated`    | `number`                     | Number of URLs created by the user.              |
| `urlViews`       | `number`                     | Total views across all user-created URLs.        |
| `sortTypeCount`  | `{ [type: string]: number }` | Object mapping file MIME types to upload counts. |

#### Example

```json
{
  "filesUploaded": 1,
  "favoriteFiles": 0,
  "views": 0,
  "avgViews": 0,
  "storageUsed": 1275067,
  "avgStorageUsed": 1275067,
  "urlsCreated": 0,
  "urlViews": 0,
  "sortTypeCount": {
    "image/png": 1
  }
}
```
